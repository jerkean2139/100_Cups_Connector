If Something Breaks

Stay calm. Have a move.

If your Claude project is slow or stuck
Switch to claude.ai with the SKILL.md pasted as the first message. Same outcome.
If Claude Code can't see the PRD.md file
Just paste the PRD content directly into Claude Code's chat. Same build, slightly less elegant.
If the build errors out mid-build
Type "continue" and hit Enter. If still stuck, paste the error back to it: "Fix this and continue."
If Railway deploy fails
Skip it. Show the working code in Claude Code. Say: "I'll deploy after — that part's not the lesson."
If the demo runs over time
Skip Phase 5 (Railway) entirely. Show what was built locally in Claude Code. Drop playbook link, take questions.
If your internet dies
Switch to phone hotspot. Stay calm. Say: "AI demos require internet. Welcome to my world."
If you go totally blank
Open the audience page on the projector. Walk through the four acts as your own outline. They were built for exactly this moment.
